# Web Scraping Project

A Python-based web scraping project that extracts quote data from a
public website using Requests and BeautifulSoup.

## Project Objective

The objective of this project is to learn how to:

- Extract structured data from public web pages
- Understand HTML structure and web navigation
- Use BeautifulSoup for parsing HTML
- Build a custom dataset
- Validate scraped data

## Website

Data Source: Quotes to Scrape

https://quotes.toscrape.com/

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV
- HTML Parsing

## Dataset Fields

The scraper extracts:

- Quote
- Author
- Tags
